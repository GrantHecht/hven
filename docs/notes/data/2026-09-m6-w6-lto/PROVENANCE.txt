THE PROTOCOL, AS DECLARED (CLAUDE.md section 7 and section 8)
  Every leg -- each configure, each build, each suite, each replay arm, each
  comparison, each install-smoke arm, the export contract -- ran SOLO, one at a
  time, IN THE FOREGROUND, held under the box build lock (`flock
  /tmp/box-build.lock`), with `pgrep -af 'cmake|ninja|ctest|hven_|bench_corpus'`
  verified in a SEPARATE command before the lock and AGAIN inside it.  Every
  retained log (.scratch/w6t3/logs/) carries PGREP_EMPTY / FOREGROUND_START /
  FOREGROUND_END inside the lock plus its own LEG_RC and WRAPPER_EXIT.  Every
  wrapper was first proven against a STUBBED failure inside the lock
  (00-fold-proof.log: eight wrappers, every WRAPPER_RC non-zero).

  ONE PROCESS WAS DECLARED AND EXCLUDED BY EXACT PID for the legs up to and
  including the LTO replay arm: pid 353157, the idle launcher shell of the
  READ-ONLY sol reviewer reading the W6 T2 commits, whose embedded review prompt
  contains the strings "ctest" and "hven_" and so matches a whole-command-line
  pgrep without being a build or a test (state S, running nothing, touching no
  tree).  It is named in each such log beside the verdict.  It exited before the
  LTO-OFF replay arm and the later logs show a plain PGREP_EMPTY.

  The six replay runs ran pinned with `taskset -c 2` at MKL_NUM_THREADS=1 and
  OMP_NUM_THREADS=1.  NO CO-RUN PROTOCOL WAS USED and none is declared: nothing
  here was measured under contention.  Builds ran at -j 8; ctest at -j 4 (the box
  protocol's ceiling).  Because NOTHING here asserts wall-clock, none of that
  parallelism touches a quotable number.

  THE STOP RULE, AND WHY IT DID NOT FIRE.  T3 carried an instruction to stop the
  artifact if a COUNTER or a STATUS column differed between the arms.  NONE DID:
  all 56 integer counter columns and all 7 string columns (status, kkt_verdict
  and the descriptive fields) are byte-identical in every cell on all three
  engines.  spread.txt computes that check from the DATA, column class included,
  and prints it as an explicit STOP TEST line per engine.

  THE TWO GATED DIFFERENCES ARE NEITHER COUNTERS NOR RESIDUALS.  They are
  `ipqp_alpha_p_min` (schema index 72) and `ipqp_alpha_d_min` (73) in the single
  cell f7_n1000_path_warm -- floating-point step-length minima that the gate's
  residual column set does not cover, moving by 1.756e-10 and 2.112e-09 relative.
  The comparator's docstring (scripts/compare_replay.py:43-45) asserts that every
  column at index >= 21 is an integer counter; that sentence is WRONG for this
  schema -- five such columns hold floats -- and it is the sentence a reader would
  use to misread these two as counter regressions.  Recorded in spread.txt and in
  README.md section 4; the comparator itself was NOT changed by this task.
