THE BOX PROTOCOL, AS RUN (CLAUDE.md section 7 and section 8)
  Every leg ran under the box build lock (`flock /tmp/box-build.lock`), with
  `pgrep -af 'ninja|ctest|hven_'` verified clean in a SEPARATE command before the
  lock and `pgrep -af 'cmake|ninja|ctest|hven_|bench_corpus'` AGAIN inside it.
  Every retained log carries PGREP_SEPARATE / PGREP_EMPTY / FOREGROUND_START /
  LEG_RC / FOREGROUND_END / WRAPPER_EXIT.  /tmp holds the lock and nothing else:
  every tree, log and artifact of this gate is under .scratch/m6-close/.

  AT THIS GATE'S START the separate pgrep matched exactly ONE line -- the
  session's own pgrep Bash call, whose command line embeds the pattern.  No
  foreign build, test or bench process ran at any point, and DECLARED_SKIP_PIDS
  was EMPTY for every leg: nothing was excluded by pid, and nothing foreign was
  ever signalled.

  EVERY WRAPPER WAS PROVEN AGAINST A STUBBED FAILURE before any real leg ran
  (suites/00-fold-proof.log, 12 wrappers, plus run_leg.sh's own
  failure-propagation proof as its own leg because a nested run_leg.sh would
  deadlock on the lock it already holds).  Each stub makes one inner command
  fail while the wrapper's LATER commands succeed, so a wrapper that reported a
  trailing tail/grep/echo's status would exit 0 and be caught.  All 13 propagated.

  THE ONE PLACE A STATUS IS DELIBERATELY NOT FOLDED is the golden rig's ctest,
  whose EXPECTED result is not all-green (docs/testing.md:1391-1404).  There the
  wrapper captures and prints ctest's status and guards instead that ctest RAN
  (a run whose log carries no "tests passed" summary line is a wrapper failure).
  That substitution is itself in the fold proof.

WALL-CLOCK
  NOTHING IN THIS GATE ASSERTS WALL-CLOCK.  Counters, statuses and test counts
  are the asserted currency; every duration recorded here is INFORMATIONAL
  (CLAUDE.md section 7).  The census's T2 cells run SOLO because their OUTCOMES
  are wall-dependent, not to produce a timing.

THE CENSUS'S CO-RUN PROTOCOL, DECLARED (CLAUDE.md section 7)
  scripts/run_walk_census.sh, parallel-tiered v1, at its defaults:
    T1  remainder, 44 cells, 6-wide, one process per pinned PHYSICAL core
    T2  wall-sensitive, 3 cells, SOLO (the machine otherwise idle)
    T3  deep-DNF, 10 cells, 5-wide, each with its FULL per-phase budget
  Tiers are assigned from the FROZEN baseline, not from this run's outcomes, so
  the schedule was fixed before the first solve.  MKL_NUM_THREADS=1 in every
  worker; every worker taskset-pinned to ONE logical CPU of a DISTINCT physical
  core, SMT siblings never both used (topology: 8 physical cores, representatives
  0,1,2,3,4,5,6,7).  Order T1 -> T2 -> T3, tier 2 starting only after every tier-1
  worker was reaped.  wall_s is excluded from every comparison by the comparator
  and is never quoted.  A deviating cell is a CANDIDATE, not a regression, until
  re-run ALONE and still disagreeing.

  Baseline: bench/baselines/2026-08-16-u0-corpus/walk_baseline.csv (the baseline
  of record since the U0 flag-unification event), READ ONLY and never rewritten.
  Comparator: scripts/census_compare.py, at its BYTE-EXACT default -- its opt-in
  --residual-gate is NOT passed, which is the M5 gate's own bar (m5-ledger:630-635
  read byte identity on all 44).
