THE CHANGE UNDER TEST (summary; the field map is the B3 manifest in the report)
--------------------------------------------------------------------------------
* CommonOptions, embedded once per engine: optimality_tol, feasibility_tol,
  max_iterations, max_factorizations (std::optional<Index>), time_limit_seconds
  (std::optional<double>), verbosity (enum Verbosity: kSilent, kWarnings, kSummary,
  kIterations), threads, start_level, infinite_bound (declared, validated, INERT until
  B7).  The IPM's kkt_tol/bar_tol map to optimality_tol (with an optional
  termination.complementarity_tol override for the barrier test), econ_tol/icon_tol to
  feasibility_tol; the SQP's kkt_tol/feas_tol likewise; max_iters/max_iter become
  max_iterations (IPM default 1000 per phase, SQP default 100).
* SolveBudget: max_iterations and minor_budget become std::optional<Index> (empty = no
  limit; an engaged value < 1 is refused at solve entry).
* New statuses SolveStatus::kWorkLimit and kTimeLimit (and their RestorationSubStatus
  images), with the two limits: max_factorizations (deterministic, read at iteration
  boundaries on both engines) -> kWorkLimit; time_limit_seconds (wall clock,
  NON-REPRODUCIBLE, never set in a replay, census, harness or runtime row) ->
  kTimeLimit.  Both default to empty.
* The SQP minor-budget (SolveBudget::minor_budget) exhaustion is RELABELLED kMaxIter ->
  kWorkLimit.  The returned point, multipliers and every counter are unchanged.
* Verbosity default kSilent on BOTH engines (the IPM was print_level 0 = full output;
  the SQP was already silent).  The console banner's stale "InteriorPointSolver" is fixed.
* IpmOptions gains `linear` (the KKT factorization knobs, incl. the dense arm),
  `termination` (acceptable and divergence tiers, acceptable-iteration count, the
  complementarity override), `advanced` (the research tier).  SqpOptions gains `linear`
  (the dense arm) and `advanced` (the research tier, incl. make_strategy and `ipqp`,
  whose ipqp_ prefixes drop).  Cryptic names renamed.  Option enums singular with
  kPascalCase enumerators; the k...Count sentinels leave the public enums.
  IpmPhase (and the option enums) leave detail/; detail/drivers/ipm_solver_fwd.h is
  deleted (R7).  FixedVariableTreatments folds into the IPM options header as
  FixedVariableTreatment (F6); model/fixed_variable_treatment.h leaves the public
  surface, the relax constants and the name function go to detail/.
* The dense arm, NAMED NOW, NOT WIRED: `linear.dense_factorization` (hven::linear::
  DensePolicy {kNever, kAlways, kAuto}, default kNever) and `linear.dense_max_dimension`
  (std::optional<Index>, default empty) on both engines.  RESERVED: validate() accepts
  only kNever and an empty dense_max_dimension and refuses anything else by name, until
  DN-1 wires the arm.
* SqpSolver(SqpOptions = {}); dump_options doubles at shortest round-trip on both
  engines; the export allow-list loses its three B3 lines.
