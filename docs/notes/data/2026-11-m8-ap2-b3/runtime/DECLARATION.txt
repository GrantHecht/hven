INSTRUMENT, per measured process (runtime_leg.sh): wait until `date +%N` < 5e6 (sub-second
phase alignment), then MKL_NUM_THREADS=1 OMP_NUM_THREADS=1 taskset -c 2 perf record -c 200000
-e instructions:u -- perf stat -x, -e instructions:u -- <arm binary> <cell args>; symbols by
`perf report --comm hven_sqp_corpus --sort symbol -F overhead,sample,sym`.
VALIDITY: THROTTLE events == 0 in every measured process; a throttled process VOIDS the leg.

before any leg. FILTER LIVENESS: INTERIOR MODE ONLY -- per arm, excluded samples summed over
the mode's processes and rounds must be > 0, else VOID. Any unparseable table line VOIDS.

per leg for interior). One untimed, unrecorded warm-up process per arm per mode. Core 2.

CRITERION, per mode: the FILTERED SUM -- instructions:u samples over every symbol EXCEPT
exactly: difftime, difftime@plt, mkl_serv_get_clocks_frequency, __vdso_time,
__vdso_clock_gettime, time, clock_gettime. Per (arm, cell) the median over 3 rounds; per arm
the sum of medians; PASS iff 0.995 <= B/A <= 1.005. The gate PASSES iff all four modes pass.
REPORTED BESIDE IT, never the criterion: raw perf-stat instructions:u, unfiltered sums,
excluded samples, per-round ratios.

missing row stops the gate. (B3's declared X2 relabel moves no row here: every replay cell is

the evidence, report, do not re-run, do not change the criterion or the analyzer after data.
