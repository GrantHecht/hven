THE CHANGE UNDER TEST
--------------------------------------------------------------------------------
RULE  detail/model/absent_bound.h: b >= infinite_bound is +inf; b <= -infinite_bound is -inf; any other value
    verbatim (NaN passes, refused by the caller). So at the default a bound exactly at 1e20 is absent and the
    largest double below it is real; infinite_bound = kInfinity is the identity ("every finite value is a
    real bound"). A bound at infinity on the wrong side becomes the infinity that describes no interval and
    is refused by the checks that refuse the infinities themselves.
WHERE once per route, where a declaration enters each engine's transcription: NlpProblemModel (an Nlp's
    variable and row bounds; the declared values are kept beside the read ones, and the per-solve re-read
    compares the declared ones); NlpModelAssembly (the SQP's box over any model); NonLinearProgram::
    set_variable_bound / update_variable_bound_values (the interior-point box, every route; the threshold
    is fixed per program, set_infinite_bound before any bound is staged); make_nlp_program carries it.
    The SQP solve's bridges are laid under opts.common.infinite_bound; the restoration sub-solve reads its
    wrapper under the parent bridge's threshold; the column-scaled solve divides the READ box and lays its
    scaled bridge under +inf. The model-taking free helpers (evaluate_kkt, build_subproblem) read the
    default threshold.
SEMANTICS (decided here, documented on CommonOptions::infinite_bound and Problem): both sides absent = free
    (a free row is passed to neither engine, g = NaN as before); equal finite bounds below the threshold =
    fixed / equality as before; refused by name with std::invalid_argument naming the declared values and
    the threshold: a lower bound read as +inf (with an infinite upper: "fixed at infinity"; with a finite
    upper: "exceeds"), an upper read as -inf, an equality row or a fixed variable at +/-threshold; NaN and
    inverted pairs refused as before (messages unchanged when the threshold changed nothing); an option
    infinite_bound <= 0 or NaN refused (B3, unchanged).
PROBLEM laid under the default (1e20); a solve under another threshold re-lays it (Nlp: transcription
    rebuilt, rows may take another kind, IPM program dropped and re-laid, counted; pieces: program rebuilt
    from its declaration with the bounds as declared; model route: program rebuilt); a pre-laid program
    (problem_from_program) or a bridge (problem_from_assembly) under another threshold is refused by name.
    A threshold that empties a pair refuses that solve and leaves the Problem as it was.
    ProblemStatistics::absent_bounds (new) counts the finite values read as absent; the census reads the
    threshold; the declaration key digests the box as read.
QP TIER the four cutoffs kEngineInfBound (walk), kIpqpInfBound (IPQP), kSsnInfBound (SSN) and
    QpDegeneracyParams::inf_bound (the degeneracy arm) retire into QpProblem::infinite_bound (default 1e20 for
    a hand-built problem; has_lower/has_upper; validate refuses <= 0 / NaN). Every SQP subproblem is stamped
    +inf (the seam's two builders; the elastic and mixed lifts and every derived copy carry their source's):
    absence is decided once, upstream. make_ipqp_box writes an effective side at or beyond the cutoff as an
    infinity and the IPQP kernels test infinity. detail::kRestorationSlackBound is +inf (was 1e20).
