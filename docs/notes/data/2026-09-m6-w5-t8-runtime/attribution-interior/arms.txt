THE ARGV LOCK. attribution.md section 6 records that instructions:u on these
cells is BIMODAL in the measured child's argv+environ byte footprint. Every
path component that varies between arms here is fixed width -- the sha is seven
characters at all eleven arms, the arm number two digits, the round one digit,
the pass one letter -- so the child's argv is 263 BYTES AT EVERY ARM, and every
batch log prints it (`ARGV_LEN`) rather than asserting it. The diff leg's short
cell spec is 71 bytes shorter, so its --csv basename carries 71 bytes of padding
and its children are 263 bytes too; the leg refuses to proceed if they are not.

order the cells were REQUESTED, three treatments per cell, MakeParameter first

bench/ipm_corpus_leg.cpp). The order above therefore makes
`f7_n1000_bound_physics/MakeParameter` the FIRST row every process writes AT
