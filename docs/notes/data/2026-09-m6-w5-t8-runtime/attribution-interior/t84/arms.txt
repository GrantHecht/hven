  THE ARGV LOCK. attribution.md section 6 records that instructions:u on these
  cells is bimodal in the measured child's argv+environ byte footprint. Every
  path component that varies between arms is FIXED WIDTH -- seven characters for
  every binary directory, patched arms included (`x1_____`, `p16384_`), two
  digits for the arm number, one for the round -- so the child's argv is 264
  BYTES AT EVERY ARM, and every batch log prints it (`ARGV_LEN`) rather than
  asserting it. The first experiment round set broke that lock by ONE BYTE and
  was RE-RUN; it is retained, unedited, under raw/round1-superseded-argv/ with
  its own README.

  CELL ORDER IS PART OF THE PIN, and it is what the R3 positional rule stands
  on. `--engine interior` writes its base rows in the order the cells were
  REQUESTED, three treatments per cell, MakeParameter first, so
  `f7_n1000_bound_physics/MakeParameter` is the FIRST row every process writes
  AT EVERY ARM. Verified before any timed sample existed, on all six arms, by
  the untimed smoke in logs/B2-smoke.log. The two rows the bench commit eb8f157
  adds are written at positions 20 and 21, AFTER every scored row, so no scored
  row runs in a different position in its process at any arm.
