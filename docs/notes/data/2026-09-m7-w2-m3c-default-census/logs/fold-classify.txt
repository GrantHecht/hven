  FOLD PASS  F1 true: sub optimal, h_out <= feas_tol, f doubled   -> QP_CAP_BUDGET
  FOLD PASS  F1 false: the gap is below the bar                   -> QP_CAP_BUDGET
  FOLD PASS  F1 false: h_out ABOVE feas_tol, however big the f gap -> QP_CAP_BUDGET
  FOLD PASS  F1/F2 N/A: restoration never ran                     -> QP_CAP_BUDGET
  FOLD PASS  F2 true: sub infeasible, h_out == h_in (the EXACT null) -> RESTORATION_EXIT(infeasible)

  FOLD PASS  F4 true: 0 accepted steps and 3 JUDGED rejections    -> QP_CAP_BUDGET

PART 4 -- the STRUCTURAL REFUSALS. A row this script cannot trust is REFUSED, never classified.
  FOLD PASS  no PROBE_END (a probe killed mid-write)              -> REFUSED(no PROBE_END -- a probe killed mid-write must never read as a row)
  FOLD PASS  a missing block (OPTIONS)                            -> REFUSED(block OPTIONS does not appear exactly once)
  FOLD PASS  the counters block declares 48 fields, not 49        -> REFUSED(the counters block declares c_field_count='48', not 49)
  FOLD PASS  the history header is one column short               -> REFUSED(HISTORY: header has 29 columns, not 30)
  FOLD PASS  the probe's own judged-rejection derivation disagrees with the counters -> REFUSED(the probe's c_derived_judged_rejections=99 disagrees with rejected_steps - qp_failures_routed = 0)

  FOLD PASS  a key the predicates read is missing (restoration_entries) -> REFUSED(missing key restoration_entries)
  FOLD PASS  a history row whose qp_status CONTAINS `=` is still a row, not a key -> START_POINT_NONFINITE
  FOLD PASS  the history's own h_rows_printed disagrees with the rows parsed -> REFUSED(the history block says h_rows_printed=99 but 1 row(s) parsed)
  FOLD PASS  the ledger's own ledger_records_printed disagrees with the records parsed -> REFUSED(the ledger says ledger_records_printed=99 but 0 record(s) parsed)
  FOLD PASS  the LEDGER block carries no LEDGER_RECORDS sub-block -> REFUSED(the LEDGER block carries no LEDGER_RECORDS sub-block)
  FOLD PASS  the file is not a probe row at all                   -> REFUSED(first non-empty line is 'hello', not PROBE_BEGIN)
