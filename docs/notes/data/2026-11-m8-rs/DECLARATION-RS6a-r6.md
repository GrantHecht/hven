## What changes relative to r1..r5
1. Owner ruling Q9: the whole-library seam executables no longer each recompile the library. tests/CMakeLists.txt defines, on first use, the OBJECT library `hven_testing_library` (the hven target's SOURCES, COMPILE_DEFINITIONS and INCLUDE_DIRECTORIES, plus HVEN_TESTING=1, ${COMPILE_FLAGS}, Eigen/fmt/threads/backend usage requirements); `hven_add_seam_executable(... WHOLE_LIBRARY)` adds `$<TARGET_OBJECTS:hven_testing_library>` instead of the library sources. One seam executable per directory is kept; none links hven::hven (the configure guards stay).
   hven_qp_seam_tests joins the shared set (was a narrow closure of 14 library TUs + the platform backend TUs): sharing is cheaper than the narrow set it replaces (the library TUs exist anyway), it retires the narrow-seam flag class (`seamdef` for the qp seam's own TUs) and its closure can no longer drift from the library's; the cost is a larger link (the whole library's objects). hven_linear_seam_tests (1 library TU + backend) and hven_kkt_seam_tests stay narrow: their closure is a handful of TUs and sharing would make them link the whole library for a test of one.
2. New configure guards (hven_check_seam_targets): (a) a whole-library seam must carry `$<TARGET_OBJECTS:hven_testing_library>` and no source under src/ of its own; (b) a narrow seam may recompile at most half of the library's TUs. Two new mutation proofs in legs/mutation6a.sh: M5a (hven_ipm_seam_tests also lists src/core/ledger.cpp) and M5b (hven_ipm_seam_tests declared with every hven source as LIBRARY_SOURCES); each must FAIL the configure with its message and PASS once restored (plus M1..M4 re-run).
3. Rebase: new test sources of the base are placed by the rule of DECLARATION-RS6a.md item 1 (membership is the directory): tests/linear/test_matching_scaling.cpp -> hven_linear_tests (it was in hven_tests); tests/qp/test_qp_platform_retake.cpp -> hven_qp_seam_tests (it was in hven_qp_walk_seam_tests). tests/qp/support/qp_engine_test_access.h is a header. Membership is re-derived from the base tree by tools/rs6a_membership.py: gates/RS-6a-r6/declared-membership-r6.txt (188 sources over 18 executables; r1 declared 186) and the object map gains one line (gates/RS-6a-r6/declared-object-map-r6.txt; r1 88 + r2 1 + r6 1 = 90 declared lines).
4. CLAUDE.md section 8's `hven_tests` is now "the ordinary `hven_<component>_tests` executables" (wording only); the comment in pardiso_session.h (MPL session file) is untouched. docs/testing.md describes the shared target.
