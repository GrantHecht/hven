   The flags diff normalises path spelling by design (it asserts the same FILE, not the same bytes); P-SYM sees the bytes. This is the design's own caveat ("gtest `__FILE__` strings change") extended to define-carried paths; DECLARATION-RS6a.md did not foresee it.
