THE DEFECT AND THE CHANGE
--------------------------------------------------------------------------------
Defect   With IpmOptions::return_best on, a non-finite abort (kNumericalError with kNonFiniteIterate /
         kNonFiniteStart, the cap-floor exit, a failed phase-first iterate, a failed initial
         factorization) set return_best_applied from the status alone: the residual columns and
         returned_best_iterate described BestIter while x was the failed point P with multipliers
         cleared (R7).
Ruling   (settler) With return_best on and a finite best iterate recorded, the abort returns the best
         iterate IN FULL (x, multipliers, bound duals, objective, every residual column;
         returned_best_iterate = true; the message names the cause and, via the existing clause,
         "; returned the best iterate"). With none recorded (start / phase-first-iterate / entry
         failures) it returns P with multipliers cleared and returned_best_iterate = false (R7).
         return_best off: unchanged.
Code     alg_impl records best_recorded where the tracker runs; the nonfinite_abort branch substitutes
         the best pair, bound duals and provenance (the converge-check exits' substitution) when
         return_best && best_recorded, else clears multipliers and sets abort_without_best, which
         clears return_best_applied at the tail. result_message.cpp needs no change (its best clause
         already rides on every status the flag is set with).
SQP      No equivalent defect: the SQP engine's only best-iterate substitution is the budget_mode
         kMaxIter door (kFinishBudgetBest); its non-finite exits return the failed point with cleared
         multipliers and returned_best_iterate false, already consistent. Unchanged.
