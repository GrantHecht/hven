instruction count depends on when in the second the process runs, not on the code under test.

spin count can be phase-correlated with the arm; the three SQP modes run one process per cell
(27 per arm per round) and average it out. hven's own new work in this leg is visible and
small: count_program + materialize_variable_bounds (the internal-route Problem's census, once
per program) = 249 samples, about 5e7 instructions, 0.05 % of the leg.
