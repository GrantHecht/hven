## (1) THE RULE — sign convention, precedence, tolerance

**Sign convention: correct in both blocks and on both bound sides (OBSERVED from `price`, `drop_worst`, `dropped_directional`, `ride_sign`).** `price` forms `r = Hx + g + Aeᵀλe + Aiᵀλi` and `z = r` on bound components, so the engine's identity is `g = −Aeᵀλe − Aiᵀλi + z`. `drop_worst` defines `viol = −λ_i(row)` for rows, `−z(i)` at lower, `+z(i)` at upper; `dropped_directional(p)` is `a_sᵀp` for a row, `−p_s` at lower, `+p_s` at upper. With `p` in the null space of every retained row/bound, `gᵀp` reduces to the dropped member's own term: row `−λ_s a_sᵀp = viol·dd`; lower `z_s p_s = (−z_s)(−p_s) = viol·dd`; upper `z_s p_s = viol·dd`. So `s = violation * dropped_directional(p)` equals `gᵀp` exactly at a KKT point of the retained set in every case. The header's phrasing "the Dantzig violation is −z_s ... so the product is z_s a_sᵀp" is loose for the upper side (`viol = +z_s`, `dd = +p_s`) but the product it names is right.

**"The predicted sign is the leaving sign, so (ii)'s feasibility half cannot veto it": a theorem, not an assumption (OBSERVED from `ride_sign`).** `viol > opt_tol > 0` for every `drop_worst` drop, so `sign(s) = sign(dd(p))`; the code picks `sign = +1` when `s < 0` (`dd < 0`) and `−1` when `s > 0`; `leaves = −dd(p)`, and the veto test is `sign·leaves < −leaves_tol`. With the predicted sign, `sign·leaves = |dd(p)| ≥ 0`, which never satisfies `< −leaves_tol`. This is pure algebra, independent of stationarity and of the bound side. The zero-multiplier probe fills a fresh `DropRecord` (`violation = 0`), so `s = 0` and the branch is inert there (OBSERVED, report §2 and the `DropRecord{}` default).

**Precedence when the point is not a stationary point of the working set.** Where drops happen (OBSERVED): `drop_worst` is called at exactly two sites in `run()` — after `x = eqp.x` with the full step taken ("reaching this line means the pass was a KKT point of the current working set", ~:990–1003) and after `refine_terminal_mu_free` adopted a refined point (~:1057–1063). Both are stationary points of the (regularized) working-set problem, so the identity holds up to the regularization/refinement residual ρ — which is precisely the term the rule is built to ignore. A warm seed never arms the ride (`dropped.active` is false on the first pass). A border retreat re-arms without moving `x` (:1718). **The one place precedence is not exact (INFERRED):** the declined-ride (iii) exchange, which re-arms the ride (`last_drop = dropped`, :1948) after the add-site code may have stepped `x` by `alpha·ride.dir` (exchanges do carry positive alpha — YORKNET qp3 it=177 in the base trace: `EXCH ... alpha=4.396e-04` followed by a `STEP` of the same alpha). On an LP `g` is constant and null(W′) = null(W) by the exchange's own construction, so `gᵀp = z_s a_sᵀp` still holds with the stale `violation`; on a face with curvature the moved point adds `alpha·dirᵀH p` and the stale predicted slope is no longer exact, while the measured slope (which NC1 used there) is. Reachable only through (iii)-exchange-with-motion followed by a sign disagreement on a non-flat face; the corpus shows no mover attributable to it (`rexch` cells YORKNET qp1/2/5/6, Hj qp1/4/9 all status- and minor-identical to base). Register, do not fix here.

**Tolerance scale.** `|s| > 1e-12‖g‖₂‖p‖₂` is, for a bound (‖a_s‖ = 1) with `p` leaving at angle θ, `|z_s| > 1e-12‖g‖/cosθ`. As a resolution floor for the multiplier that is the right currency (`z_s` is priced by cancellation in `g − Aᵀλ`, so its noise is ε·‖g‖·cond, and 1e-12‖g‖ is ~4500ε‖g‖) — a large `‖g‖` with a tiny multiplier is correctly read as unresolvable. The mismatch is the `cosθ` factor: a resolving multiplier on a `p` that barely leaves the constraint (a 1/δ-sized regularized step that lives mostly in the face) can fail the test while `|z_s|` is well above `opt_tol·stat_scale`. That case then falls to the measured slope — which is the base behaviour — but see (3) for what the kPtNoise mark then does with it.
