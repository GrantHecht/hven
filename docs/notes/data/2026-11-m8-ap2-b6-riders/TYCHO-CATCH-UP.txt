R-T1 Shared Jacobian entries are serialised by the layout (C235). NonLinearProgram now sets
     SolverIndexingData::unique_constraints_ on every partition copy of a constraint function at
     each lay: false when one of the copy's rows is also named by an application in another
     partition, true otherwise (always true on one partition). A raw piece's Jacobian scatter must
     honour it the way hven's raw sites do -- lock the entry's column (clashes[col] != -1) when
     !d.unique_constraints_ -- for a shared-row declaration to be race-free; a raw piece that
     never locks its Jacobian stays race-free only on declarations without cross-partition shared
     rows. tycho's raw scatter sites (its kkt_fill_all equivalents) should be checked for that
     condition when tycho consumes this head. The local-block layer honours it.
R-T2 A piece must be copy-constructible (C236 R1). The handles already copied deeply; a
     non-copyable piece type now gets an authored compile-time message on the direct-storage
     route ("hven constraint adapter: a piece must be copy-constructible ...") instead of a raw
     instantiation failure. Hook types are unaffected (the hook emplaces the payload).
R-T3 A class with a static member `kInputs` is a local-block piece: it is routed to the
     local-block adapters, and one that does not meet their shape is refused by name. A search of
     tycho's include/ and src/ on 2026-11-04 found no type declaring kInputs. solver_interface_specs.h
     now includes local_blocks.h at its end.
R-T4 SolverFunctionBase::print_data and NonLinearProgram::print_data are removed, with the
     <iostream> include of solver_function_base.h and detail/model/non_linear_program.h (C236 R7).
     A tycho TU that used std::cout through those headers names <iostream> itself. A search on
     2026-11-04 found tycho calling ObjectiveFunction/ConstraintFunction::print_data() at twelve sites,
